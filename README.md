## Setup
<!-- **For a detailed guide, see: https://lancellc.gitbook.io/clash** -->

1. Open **ClashX**
2. Click **ClashX icon** in the status bar
3. Click **Config** and then **Remote Config**
4. Click **Manage** and then **Add**
5. Paste a **[Subscription Link](#subscription-links)** to the **url** field
6. **OK!!** (manually select a node if necessary)

## Maintaining subscriptions

Edit sources in [`combine/sources.json`](combine/sources.json), then run from the repository root with dependencies installed:

```sh
python -m combine.sources
python -m combine.refresh
```

Subscriptions refresh automatically every eight hours. Empty results or a drop below half the published entry count preserve both previous subscriptions. Check [source health](combine/health.md) for results; node connectivity is not tested. See the [maintenance guide](docs/maintenance.md) for setup, validation, and troubleshooting.
